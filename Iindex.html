Evaluasi Indeks Pencemaran (IP)

IP memerlukan nilai baku mutu yang sesuai peruntukan perairan dan metode perhitungan resmi. Versi ini menyediakan kalkulator transparan berbasis pasangan nilai Ci/Li; pengguna harus memasukkan baku mutu yang sah dan memeriksa aturan parameter dengan nilai maksimum/minimum.

Backup dan pemulihan data

Mode hybrid V1.0: data utama disimpan di browser (IndexedDB), lalu dapat diekspor sebagai JSON untuk backup atau dipindahkan ke perangkat lain. Sinkronisasi server memerlukan URL API milik organisasi.

Validasi dan status sistem

  • Data contoh stasiun ditandai sebagai lokasi placeholder, bukan koordinat survei.
  • Data kualitas air tidak diisi otomatis agar tidak menimbulkan klaim hasil pengukuran palsu.
  • Interpolasi IDW hanya dijalankan jika terdapat minimal dua titik valid dengan koordinat dan nilai numerik.
  • Sinkronisasi cloud tidak aktif sampai endpoint API tersedia dan sesuai format JSON MarineWatch.
